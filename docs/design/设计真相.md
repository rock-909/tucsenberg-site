# 设计真相

## 当前方向

Tucsenberg 采用克制、工程可信的 B2B 视觉方向：先让买家理解产品和规格，再用结构、线条和少量动效建立品牌识别。页面不能用装饰掩盖产品事实、性能限制或询盘入口。

方向 E 是当前 owner 已裁决的视觉候选，但 HTML 样稿不是运行真相。其未完成落地约束必须在实现前重新验证；与当前代码、组件治理或无障碍行为冲突时，以运行行为和明确的新裁决为准。

## 硬边界

- 主内容和主要 claim 默认可见，不依赖 JavaScript reveal；
- 设计优先复用正式 UI 入口；
- 颜色、网格、页面模式、组件和动效分别由本目录其他四份文件负责；
- 不为了高级感增加长动画、客户端边界或新依赖；
- reduced-motion、键盘焦点、对比度和窄屏布局是基本要求。

## 读取顺序

设计调整先读本文，再按改动范围读 设计系统、组件治理、页面模式或动效治理。历史视觉翻译、样稿和被否方向不作为当前规则。
