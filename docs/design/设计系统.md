# 设计系统

## 真相来源

CSS token 和组件实现是运行真相；本文档解释角色和使用边界，不维护一份独立数值表。

## 颜色

颜色按角色使用：背景、正文、弱文本、边框、品牌强调、状态和反差文字。新颜色必须先有明确语义，不为单个页面随意增加近似色。

## 令牌

优先使用现有 CSS custom properties、Tailwind token 和正式 UI 组件。不要在页面里复制颜色、间距、圆角或阴影常量。令牌变化要同步组件治理和受影响的页面模式。

## 网格

网格用于建立内容节奏和装饰锚点，不得遮挡正文、焦点环或主要 CTA。装饰层必须不影响可读性、点击和 reduced-motion。

## 变更验证

设计系统变更至少检查：桌面/移动布局、主题对比度、键盘焦点、首屏内容可见性和相关组件测试。
