# 页面模式

## 页面骨架

页面按清晰的阅读顺序组织：标题和核心 claim -> 产品或证据 -> 规格/解释 -> CTA 或询盘入口。普通 section 使用一致的容器、标题层级和垂直节奏。

## 产品页

产品页必须先说明产品身份和适用场景，再呈现规格、图示、下载和询盘入口。示意图必须诚实表达，不把装饰图当工程证据。

## 表单和 CTA

CTA 文案说明下一步动作。表单字段保持最少必要集合；错误就地、可读、可恢复。主要入口不能被动效或 sticky 装饰遮挡。

## 响应式和无障碍

窄屏优先保证正文、规格、键盘顺序和触控目标。布局变化不能依赖 hover；焦点、对比度和无 JS 内容必须保持。
