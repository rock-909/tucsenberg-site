- [ ] **Step 3: 写 `public/_headers`**

把 `public/_headers` 改成（原有的 `/_next/static/*` 段一个字不动）：

```text
/_next/static/*
  Cache-Control: public,max-age=31536000,immutable

const TURNSTILE_RESCUE_TIMEOUT_MS = 15_000;

  const [hasWidgetLoaded, setHasWidgetLoaded] = useState(false);
  const [hasFailed, setHasFailed] = useState(false);
  const [hasTimedOut, setHasTimedOut] = useState(false);
  // 「从来没拿到过令牌」——用 ref 而不是 state，因为提交后令牌会被清空重置，
  // 那段空窗期不算「拿不到」，不能重新计时。
  const hasEverHadTokenRef = useRef(false);

  useEffect(() => {
    if (!hasWidgetLoaded || hasEverHadTokenRef.current) return undefined;
    const timer = setTimeout(
      () => setHasTimedOut(true),
      TURNSTILE_RESCUE_TIMEOUT_MS,
    );
    return () => clearTimeout(timer);
  }, [hasWidgetLoaded]);
```
