# 内容与品牌

## 内容入口

- 品牌事实：src/config/single-site.ts；
- 页面表达：src/config/single-site-page-expression.ts；
- SEO 与 crawl：src/config/single-site-seo.ts；
- 页面正文：content/pages/en/*.mdx；
- UI 文案：messages/base/**、messages/profiles/b2b-lead/**、messages/profiles/catalog/**；
- 产品事实：src/constants/tucsenberg-product-page-*.ts 和 assembled product pages。

不要把长正文塞进 messages，也不要在页面组件里硬编码用户可见文案。

## 页面字段

- title / description：页面内容输入；
- seo.title / seo.description：metadata 输入；
- updatedAt：买家可见内容变更；
- lastReviewed：人工复核时间，法务和联系页尤其需要维护。

## i18n

新增或删除语言时先改 locale 配置，再补 messages 和 MDX。不要只复制页面文件。每次 message pack 变更运行 pnpm content:check。

## 品牌边界

文案必须准确表达产品、规格、交付和询盘承诺。旧 starter 文案、占位 profile、未经 owner 确认的供应商或性能声明不能进入公开内容。

## CMS 边界

当前模型是 content-as-code。若增加 CMS，只能先做 Git-backed MDX 编辑层，不替换代码和审核后的内容真相。
