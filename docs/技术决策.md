# 技术决策

这里只记录仍有效、且原因不能仅从代码读出的决策。

## Content-as-code

页面正文、messages 和产品事实继续由 Git 管理。CMS 若出现，只能先做 Git-backed 编辑层。原因是审核、版本、回滚和部署需要可追踪真相。

## English-only public surface

当前公开站点不暴露 locale 前缀和语言切换。i18n 管道保留，待真实多语言需求出现再扩展。原因是当前业务范围单一，提前暴露语言入口会制造伪功能。

## 单一询盘写入口

表单、验证、产品上下文和 provider handoff 统一到一条真实链路。重复 Contact/RFQ 写入口不保留。原因是重复写入会造成 owner 追踪和错误处理分裂。

## Server-first UI

默认使用 Server Components，只有真实交互才进入 Client。原因是首屏、SEO、无 JS 可读性和客户端边界预算。

## Cloudflare/OpenNext proof 分层

普通 build、Cloudflare build、Wrangler dry-run、部署 smoke 和真实服务 receipt 分开判断。原因是不同层证明不同事实，不能用本地绿灯替代外部运行证明。

## 重新打开条件

业务范围、真实性能瓶颈、平台生命周期、provider 约束或多语言需求发生变化时，重新评估对应决策。
