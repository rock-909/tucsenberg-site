# 带扩展名的不存在地址返回 500 而非 404

**发现时间**: 2026-07-25（整改 Wave 5 移除废弃图片后的预览验证）
**状态**: **已修复** — 2026-07-25
**影响面**: 所有不存在的、路径里带点的地址

## 现象

生产构建下访问任何不存在的带扩展名地址，返回的是 `500 Internal Server Error`，
而不是应有的 `404 Not Found`：

```
/random.txt              → 500
/does-not-exist.svg      → 500
/next.svg                → 500   （Wave 5 移除后）
/nope                    → 404   （不带点的地址正常）
```

Wave 5 移除的五张废弃图片里，`/images/*` 四个走 `public/` 静态目录仍返回 404，
只有根目录的 `/next.svg` 落进这个坑。

这是主干上早就存在的问题，不是 Wave 5 引入的（在 `a1af99b` 上同样复现）。

## 根因（修复时更正过一次）

**最初的判断是错的。** 本文档最早写的是"没有根级 404 页，Next 找不到兜底页只能抛错"，
并据此把修法定为打开 Next 的 `experimental.globalNotFound` 实验开关。

实测服务端日志推翻了这个判断：

```
⨯ Error: Unknown locale: random.txt
    at Module.O [as generateMetadata]
```

真实链路是：

1. `src/middleware.ts` 的 matcher 为 `/((?!api|_next|.*\..*).*)`，
   **带点的路径被排除**，拿不到 locale 改写。
2. 这类请求原样落到 `[locale]` 动态段上，Next 把 `random.txt` 当作 locale 取值。
3. `[locale]/layout.tsx` 里其实有 `if (!isLocale(locale)) notFound()` 的校验，
   但**元数据生成先于布局渲染执行**，`getLocalizedPath()` 拿到非法 locale 直接
   `throw new Error("Unknown locale: ...")`，于是变成 500。

也就是说：不是"没有兜底页"，而是**非法的 locale 取值被放进了路由，代码在校验之前
就抛异常**。

按实验开关那条路走过一遍，加了 `globalNotFound` 与对应的全局 404 页面文件
后重新构建，`/random.txt` 仍然是 500——因为请求根本没走到"找不到路由"那一步，
而是在元数据生成里就炸了。该方案已弃用，试验文件移入废纸篓，仓库中不保留。

## 修法

`src/app/[locale]/layout.tsx`：

```ts
export const generateStaticParams = generateLocaleStaticParams;
export const dynamicParams = false;
```

`dynamicParams = false` 是 Next 的正规路由段配置（非实验性）：不在
`generateStaticParams` 返回值里的动态段取值**直接返回 404**，在路由层就拒掉，
任何 handler 都拿不到非法 locale。

选它而不是实验开关的三个理由：

1. 治的是根因（非法段进入路由），不是症状（没有兜底页）。
2. 非实验性，不需要按 `.claude/rules/cloudflare.md` 另开实验特性的验证通道。
3. 改动是两行配置，没有新增页面、样式、字体或文案。

`cacheComponents` 目前为 `false`，该选项可用；若将来重新启用 Cache Components，
按官方文档 `dynamicParams` 不再可用，这条要连同那条路线一起复核。

## 防回归

`tests/e2e/not-found-status.spec.ts` 断言六个不存在的地址（含带点与不带点两类）
全部返回 404，同时断言真实存在的资产仍返回 200。

## 验证

```bash
APP_ENV=production pnpm build
pnpm exec playwright test tests/e2e/not-found-status.spec.ts
```

回归检查（修复后实测）：首页、产品列表、询价页、联系页、关于页、产品详情页、
`sitemap.xml`、`robots.txt`、`/api/health` 全部 200；退役的 `/zh` 仍 404；
`/en/about` 仍 307 重定向到无前缀地址。
