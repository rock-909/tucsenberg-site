# 架构与行为

## 内容到页面

页面注册在 src/config/pages.config.ts。页面正文来自 content/pages/en/*.mdx；UI 文案来自 messages/base/** 与 messages/profiles/**；页面组合、导航、SEO 和产品目录来自 src/config/**。生成的 content manifest 不手改。

## 公开行为

- canonical URL 不带 locale 前缀；
- 非法和不存在路径必须按当前路由契约返回正确状态；
- 页面正文在 #main-content 中服务端渲染一次；
- PDF 和其他受保护文档不能被搜索引擎索引；
- 用户可无 JavaScript 读取主要页面内容。

## 询盘链路

公开表单 -> 服务端 schema / Turnstile 校验 -> 产品上下文服务端确认 -> 单一写入口 -> provider receipt -> owner 通知确认。

真实 provider、Cloudflare 和 owner inbox 的证据不能用本地测试替代。

## 渲染与平台边界

优先 Server Components。只有真实浏览器状态或交互需要时才进入 Client。不要为了动画、表单外观或 speculative streaming 增加客户端边界。

OpenNext 构建和 Wrangler dry-run 是平台证明；本地 Next 构建、CI 绿灯和预览 smoke 不能单独证明生产公开上线。

## 真相优先级

运行态和实际服务 > 捕获流量 > 当前配置和测试 > 稳定正本文档 > 历史 spec、计划和审查证据。
