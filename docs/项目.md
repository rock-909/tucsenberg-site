# 项目

Tucsenberg 是面向 OEM / 批发客户的英文 B2B 防洪挡板官网。

## 当前目标

- 展示产品并帮助买家比较规格；
- 提供 PDF 下载和报价准备；
- 承接 Request Quote / Contact 询盘；
- 在 Cloudflare 上稳定部署 OpenNext 站点。

## 当前公开范围

- 只有英文公开站点；
- 公开路径不带 locale 前缀；
- 产品线：ABS flood barriers、Aluminum flood gates、Absorbent flood bags、Flood tube dams、FRP flood barriers；
- PDF 下载必须保持 noindex。

## 非目标

这不是通用 starter、博客系统或多站点 profile 平台。旧 starter 资料、旧 locale 路由、旧产品命名和历史计划不能覆盖当前运行事实。

## 主要用户旅程

产品发现 -> 查看产品详情和规格 -> 下载资料 -> 提交 OEM / 批发询盘 -> 由真实服务和 owner 处理后续。

当前产品事实以代码和内容入口为准：产品配置、MDX 页面、消息包和站点配置优先于旧文档。
